# 岩矿实验室薄片制片流转系统

按角色登录的薄片制片流转系统：建档 → 批量录入 → 按制样规程逐步推进（每步留操作人/时间/依据）→ 镜下观察 → 缺陷闭环 → 交付/退回/复检，全程留痕。

## 运行

```bash
npm start          # http://localhost:3025 ，数据保存在 data/lab-db.json（重启不丢）
npm test           # 端到端验证（独立端口 3199 + 临时库，不影响正式数据）
npm run seed       # 向运行中的 3025 实例灌入演示数据（需空库）
```

## 业务规则

- **工序规程**：切片 → 粗磨 → 粘片 → 磨薄 → 盖片 → 镜下观察，顺序由服务器裁定；表单签发工序号与服务器状态不一致即拒绝（禁止跳工序、回退、重复提交）。
- **交付门禁**：薄片未走完、镜下结论为空、缺陷未闭环，任一存在即禁止交付；已交付批次禁止再交付、退回或操作薄片。
- **退回/复检**：仅审核员可退回（必填原因），退回后须复检（必填结论）才能再次交付，全部留痕。
- **逾期**：每工序有标准工时（12-48h），超期在批次列表与批次页红色标注。
- **下一步负责人**：按批次/薄片当前状态显示负责角色。
- **留痕**：建批次、建样本、批量录入、工序推进、镜下观察、缺陷上报/闭环、交付、退回、复检均记录操作人、角色、时间、依据。
